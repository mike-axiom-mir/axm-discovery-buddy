# Discovery Index v0.1

## Purpose

Materialize one bounded answer to a recurring AXM scale problem: future humans and machines should be able to discover what repositories exist and which declared capabilities they expose without relying on chat memory or one manually maintained list.

The scanner is deliberately local-first and read-only. It produces evidence; it does not install, merge, promote, execute, or make another repository authoritative.

## Executable bridge

Discovery Buddy recognizes two existing AXM evidence seams without importing their code:

1. `.axm/beacon.json` — repository interest/tag/protocol metadata from the existing Organ Beacon contract.
2. `registry/*capabilit*.jsonl` — capability declarations, including `registry/capabilities.jsonl` generated by `axm-collaboration-platform`.

Only whitelisted fields are retained. Unknown fields are ignored rather than copied blindly. Each accepted registry record keeps its source path and line number so a consumer can return to the exact declaration.

This makes the relationship:

`existing repo evidence -> Discovery Buddy adapter -> deterministic fleet index/map`

not:

`Discovery Buddy -> mandatory shared runtime dependency`.

## Deterministic identity

The index has schema `axm.discovery-index/v0.1`. Its `content_sha256` covers the schema, scan policy, and normalized repository records. Wall-clock time is intentionally absent from identity, so unchanged workspace evidence yields the same index digest.

`verify` rebuilds the expected outputs in memory and compares exact bytes. It never refreshes a stale map silently.

## Privacy boundary

Local mode:

- may report workspace-relative repository paths;
- never writes the absolute scan root into the index;
- never exports arbitrary source contents;
- hashes only bounded named evidence files (`README.md`, `AGENTS.md`) and parsed discovery metadata.

Public mode is fail-closed. A repository is omitted unless `.axm/discovery-public.json` explicitly says `public: true` under schema `axm.discovery-public/v1`. Public output strips local paths and Git work-state fields.

The marker states export intent only. It does not prove licensing, release readiness, runtime correctness, or safety.

## What this does not prove

A capability declaration is not runtime evidence. A beacon interest is not correctness. A Git head is not CANON. A deterministic index is not proof that every relevant repo, branch, file, or external source has been included. Scale and performance remain unclaimed until measured on large real workspaces.
